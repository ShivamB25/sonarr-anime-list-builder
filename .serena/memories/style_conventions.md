TypeScript is strict mode enabled. Code style favors functional React components, exported default page/component functions, local `type Props` aliases, async/await for network flows, and concise helper functions. Imports use double quotes and alias `@` for src is configured, though many files use relative imports. UI styling uses Tailwind utility classes plus CSS custom properties from src/client/index.css. Server code uses small route modules with Hono handlers and typed Env bindings. Naming is camelCase for variables/functions, PascalCase for components/types, and uppercase string constants for anime seasons.
