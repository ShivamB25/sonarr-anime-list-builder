After code changes, determine and run relevant validators before finishing. From package.json, prefer Bun package scripts: `bun run build` for build validation and `bun run db:migrate:local` / `bun run db:migrate:remote` for database workflows. There are currently no dedicated lint or test scripts defined in package.json, so build validation is the primary available project-wide check unless the task requires narrower runtime verification. Before commits, review `git diff --cached` and `git status` for scope and secrets. Always prefer Bun/Bunx over npm/npx for this repository.
