Airing List Web is a full-stack TypeScript app for browsing seasonal anime, managing custom anime lists, and exposing Sonarr-compatible list/feed endpoints. Tech stack: Cloudflare Workers + Hono backend, D1 + Drizzle ORM for persistence, React 19 client built with Vite, Tailwind CSS v4 styling, Bun tooling, Wrangler deployment, and @chenglou/pretext for text measurement. Codebase structure: src/client contains React app, components, hooks, and pages; src/server contains worker entrypoint, routes, db schema/helpers, and lib utilities; drizzle stores migrations; dist/client is the built frontend asset output. Runtime entrypoint is src/server/index.ts with wrangler.toml wiring the Worker and D1 binding.
